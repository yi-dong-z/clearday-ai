# DESIGN

## Register

Product UI. Design serves the task.

## Visual Direction

Efficient, restrained, and trustworthy. The interface should feel like a compact planning workspace, not a landing page.

## Color

- Neutral near-white background.
- White panels.
- One blue accent for primary actions and active state.
- Semantic red and green only for error and success.

## Components

- Cards use 8px radius.
- Buttons and inputs use consistent 6px radius.
- Borders define structure; shadows are avoided.
- Skeleton blocks are used during generation.

## Typography

- One sans family: Geist.
- Fixed product UI scale.
- Balanced headings, readable body text, tabular numerals for time and saved counts.

## Layout

- Desktop: input panel on the left, timeline workspace on the right, history below.
- Mobile: stacked panels with controls first, result second, history third.
- No nested cards inside decorative cards; framed panels only where they support the workflow.
